# audit_parts — 子代理核对草稿

每个文档一个产出文件（DD01.md / DD02.md / DD03.md / DD04.md），格式：

## 矩阵

| 条目ID | 文档条目（含节号） | 状态 | 证据 | 缺失点/说明 |

状态：✅ 已实现 / 🟡 部分实现 / ❌ 未实现 / ⚪ N/A
证据：文件:行、提交哈希、测试名、报告路径+段落，并标注证据等级 L1(代码+单测)/L2(集成实验)/L3(实验报告)/L4(仅代码存在性)

## 效果证据（如适用）

功能点 → 量化指标 → 来源 → 置信度

## 待主会话复核的问题（如有）

- 不确定的判定、文档间矛盾、疑似遗漏的检索路径
