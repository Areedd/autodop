## 噪声处理与限制

- 原有 3% 中位数差异门槛产生 3,193 个候选排序对。进一步要求较快配置的三次最大值
  小于较慢配置的三次最小值，剔除 1,508 个区间重叠的排序对，保留 **1,685 对**。
  所有 576 个配置样本保留，没有依据速度收益选择查询。这是观测区间不重叠，不能当作统计置信结论。
- 54 个配置的 `(max-min)/median` 超过 20%；配置延迟 CV 中位数约 4.28%，最大约 31.11%，
  62 个配置 CV 超过 10%。完整三次延迟和离散程度均可追溯，不能声称数据没有噪声。
- Q17 返回 0 行，保留并明确标记。其输出一致性检查证明力有限，其余 35 个模板返回非空结果。
- 结果摘要保留重复行和类型、忽略行顺序；Decimal 精确，浮点数按 8 位有效数字量化。
  因此不是浮点逐位相等，也不是对 ORDER BY 或数据库引擎正确性的独立证明。
- 装载检查覆盖显式映射、全部行数、日期／商品键及引用，没有逐字段独立重算全部数据、检查全部外键。
- 仅覆盖单一 SF10、单环境、串行负载；模板 ID 隔离不代表查询家族完全隔离，例如 Q56/Q60
  有相关结构。还需要 SF100、不同负载和并发环境才能评价跨规模／跨环境泛化。
