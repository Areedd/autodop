# AutoDOP 异构查询实验测试报告（蒸馏与持续并发补充版）

本轮补充实验已收集并核验：学生本地决策加速30.06倍，固定配置SQL回放平均延迟降低11.18%。本轮存在AutoDOP吞吐下降点，尚未达到“各档观测平均吞吐严格不下降”；下降点完整保留。

本报告汇总冻结90条查询上的端到端性能、成本模型对照、搜索检索效率、策略阶段消融、并发性能及调优成本。前九节保留前期实验范围；第十节补充匹配教师—学生与持续stream实验。采集完成、配置可部署和吞吐稳定验收分别判断。 结论按实际证据限定，不以“所有组件全面领先”作为完成声明。完整探索记录保留在附录。

## 1. 实验目标与评价口径

核心问题是异构fragment DOP能否优于查询级统一DOP；模型以成对排序准确率评价，搜索以相同评分质量目标下的检索命中率、评分次数和实际搜索时间评价。SQL执行延迟作为搜索输出质量参考，不再要求改进搜索平均执行延迟领先。并发同时报告平均、尾延迟、批次耗时及失败情况。

Transformer与竞争边作为整体建模方案，不单独删除竞争边。历史多阶段训练作为实际训练来源披露，不作为论文新增核心方法，不要求历史每阶段重训消融。已有最后策略阶段消融作为补充，不冒充删除整个蒸馏。

## 2. 环境、查询与数据

历史SQL实测服务器CPU为Intel(R) Xeon(R) Platinum 8457C，主串行实验BE版本为3.5.17-041cd01；同机3个BE，各绑定8 CPU、容器16GiB内存，上报MemLimit11.520GB。基础数据为TPC-DS SF100，实验SQL为结构化构造查询，非标准TPC-DS或TPC-H查询集。并发预算实验采用修正BE与checkpoint隔离FE，其环境与主串行分开解释。

离线环境：Python3.12.2、PyTorch2.9.0、NumPy1.26.4、XGBoost3.0.5。本次新增检索计时绑定CPU34、单线程。服务器并非排他独占；SQL采集采用既有空闲门槛及分组控制。部署二进制摘要以各阶段记录为准，仓库HEAD不替代实际版本。

90条查询在本轮前由历史200条按优势筛选并冻结，本轮没有再次筛选。2/3/4分支分别9/31/50条；根运算INNER/FULL/UNION/LEFT分别25/22/20/23条。带分支标记有序结构90种，去标记70种；结构签名数量不等于独立语义或业务场景。

当前模型开发集含114训练计划、1365配置及6702条存储训练对；验证集22计划、212配置，统一有效排序对920条（历史699、复杂221）。训练对保留批次内测量，不直接用聚合时延改写。归一化仅使用训练数据；90条报告查询不参与梯度或检查点选择，但验证集和报告查询已反复分析，不能称独立盲测。

主串行每配置预热1轮、正式3轮，先按查询平均，再对90条计算mean/p50/p90/p99。原生对照关闭AutoDOP、pipeline_dop=0；固定4直接设DOP4；最佳统一DOP为同批DOP1/2/4/8/16中各查询三轮均值最小者。所有配置共同关闭runtime adaptive DOP、query cache、spill，故“原生”是受控配置而非产品默认设置。AutoDOP采集调用超时1000ms，采集后恢复50ms。

实验模型身份分别固定：端到端使用原部署策略；搜索使用冻结原教师及已验证词表扩展；新增920对排序比较使用错对强化/EMA的三个开发检查点。后者未部署，不能把其排序结果和原策略SQL延迟拼成同一新模型的端到端验证。

## 4. 成本模型与显式DOP交互项

主指标固定为历史/复杂两组排序准确率等权平均；真实延迟差小于3%的对统一排除，预测并列算错。固定17/29/43全部保留，不挑最佳种子。下表为同一920对上的模型及输入表示整体比较，非相同初始化、相同训练历史的纯架构干预。

| MLP排序 | 86.173% | 完整显式交互特征，100轮 |

| 增强XGBoost排序 | 88.106% | 保留DOP乘积项；结果保留 |

Transformer均值优于基本XGBoost和上述MLP，但低于增强XGBoost，且不是每个种子均优于所有MLP。基本特征对照范围是在观察过旧结果后确定，应明确披露。XGBoost全行全列采样下三个种子结果相同，不代表三份独立数据。

当前Transformer开发训练使用历史教师初始化，接续30轮、每轮624对、batch16、Adam学习率1e-4，每10轮刷新训练错对池并使用0.99参数EMA；这些是实际训练设置，不宣称为论文原有独立贡献。XGBoost为200棵树、深度3/6两档。MLP为64/64隐藏层、100轮、两档学习率。不同模型训练预算及初始化不同，不能据此将全部性能差异归因于架构。

## 5. 搜索检索效率与结构消融

先完成4开发查询的小测，再对全部90条统一离线计时。六方法、3种子、每种子1次正式计时，共1620次正式搜索、540次预热；每次64候选评分。模型、竞争边实现、静态缓存和合法候选域相同。等价分组将组内DOP绑定，移除分组及独立随机搜索不作绑定，搜索空间差异是该消融的一部分。

原MCTS已有注意力排序与等价分组；改进组在此基础上加入合法统一DOP锚点、按锚点评分尺度归一化回报，并以25%随机/75%当前最好配置补全未决变量。锚点评分及重复评分都计入64次预算。去注意力和去等价类组分别在改进组上删除相应机制，其他改进保留。因此不能把改进组对原MCTS的全部收益仅归因于注意力或等价类；这些搜索实现细节须与论文方法描述同步。

每查询在搜索计时前，用独立固定随机种子2026091477生成256个参考候选、评分并去重，冻结其评分90/95/100百分位目标。参考候选不输入搜索；评估准备额外需要23040次评分，不计入任何方法搜索耗时。该分布不是全空间最优，也不是SQL延迟最优；不能将最高参考分称为全局最优。
