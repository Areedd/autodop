# 六模型对照：MLP与XGBoost移除显式DOP乘积项

本轮重新训练MLP与XGBoost的排序、回归四组；Transformer两组复用已核验的同条件从头训练结果。共同使用114个训练计划、1365条配置，监督来自6702条训练对的1363个配置端点；验证为212条配置和920个有效排序对。三种子17/29/43、两档参数及选模规则与完整特征版完全相同。验证集参与选模，属于开发集结果。

移除的是log1p(DOP)×数值特征及log1p(DOP)×类别one-hot特征，经四种池化后共532列。保留DOP自身统计、原始数值/类别汇总及依赖/竞争边统计。XGBoost实际输入556维；MLP保留1088维接口，将532个归一化乘积列置零，因此只有556个保留特征列，同时与完整特征版保持相同初始权重和网络容量。Transformer仍使用DOP嵌入与图结构，不输入这些手工乘积项。
