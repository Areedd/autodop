# 六组模型统一条件实验结果

本次比较统一使用114个训练计划的1365条配置和6702条训练对，验证为22个计划、212条配置；有效排序对共920条，其中历史699条、复杂221条。为匹配两种损失的监督来源，六组实际训练标签均取训练对的端点，覆盖1363条配置；另两条无训练对的配置只参与训练侧特征归一化。六组全部从头训练，不使用历史多阶段初始化、EMA或错对强化。验证集已被历史开发反复使用，并用于本轮选模，因此属于统一条件的开发集对照，而非独立盲测。

三个种子为17/29/43。Transformer和MLP每种目标均训练30轮，学习率为0.0003/0.001两档；每轮624对、每批16对，两个目标使用完全相同的端点和测量标签，初始化也相同。排序使用动态间隔hinge，回归使用训练权重标准化的log1p时延MSE。每5轮验证，以等权排序准确率优先、候选选择损失次之选模。

XGBoost均为200棵树、深度3/6两档、学习率0.05、全行全列采样，使用与神经网络同来源的全部训练对端点及等价权重。MLP与XGBoost均保留完整1088维特征和显式DOP交互项；Transformer使用完整依赖/竞争图。输入信息来源一致，但图与池化向量表示不同；树数与神经网络轮数不表示相同计算预算。
