# 模型与搜索验收口径

> 当前90查询测试报告已完成，范围以 [最终正文](FINAL_REPORT.md) 和 [实验覆盖清单](FINAL_DELIVERY.json) 为准。完成实验不表示所有组件全面领先或标准合同验收通过；下文历史开发门槛和进度按原记录时点理解。

> 最新搜索口径：检索效率优先，不再要求平均SQL执行延迟领先。比较共同候选质量目标的命中率、评分次数和实际搜索时间；SQL延迟作为质量参考。见 [检索效率复核](retrieval_efficiency/REPORT.md)。

> 当前范围更新：历史多阶段训练逐阶段重训不再作为必需消融；实际初始化、数据和训练成本仍披露。XGBoost基本特征对照已获用户接受，增强特征结果保留；MLP交互项三种子对照已完成。最新720次搜索预算执行已完成，64预算改进搜索平均比随机慢2.00%、p99降低12.50%，尚不能宣称全面领先。当前任务范围与证据见 [论文实验范围](PAPER_EXPERIMENT_SCOPE.md)。下文历史进度按记录时点理解。

用户明确：Transformer 不要求新增实际 SQL 延迟比较，但成对排序准确率必须优于其他方案。搜索方案仍需比较实际查询延迟，并单独报告调优开销。

- 模型对照包括 Transformer（含竞争边）、XGBoost 排序/回归、MLP 排序/回归；使用同一评估候选对、延迟标签、有效差距阈值和分数并列处理方式。
- 保留已冻结的开发集选模指标：历史与复杂查询两组准确率等权平均，同时报告汇总候选对准确率及各组结果，不能事后切换指标来宣告达标。
- 使用全部三个预定种子，不挑选最佳种子。报告查询集不参与梯度训练或检查点选择；已反复分析的数据不能称为全新盲测集。
- 未优于对照时继续进行开发数据上的模型与训练调整；此前结果仍保留，准确率优势不直接等价于查询延迟优势。

此前核验：分数间距校准模型三个种子均已完成100轮训练及独立排序重放。920对汇总准确率均值86.920%，两组等权准确率均值86.545%；XGBoost成对排序分别为85.217%、88.106%。汇总领先，但既定主指标尚未达标。90条查询已有1091个实测配置上的离线复核也已完成，未执行新SQL；Transformer三种子均值87.591%，XGBoost排序88.077%，MLP回归88.765%。完整数据见structure_coverage20/calibration_accuracy_comparison与calibration_observed90。

最新补充：三个固定种子的等权分数集成在开发集两组等权准确率为88.693%，XGBoost排序为88.106%。同一集成在90条报告查询上的排序准确率为88.372%，XGBoost排序为88.077%，MLP回归集成为89.361%。因此仍未达到优于所有对照的目标，集成也不能替代单模型结果。数据见structure_coverage20/hard_pair_ema_ensemble与hard_pair_ema_ensemble_observed90。

当前小测：pair_gap_pilot保留原多阶段初始化、图结构与竞争边，仅将损失改为批次内成对对数延迟比回归。先2轮重放验证，再seed17的30轮小测；优于匹配对照及XGBoost才扩大测试。此小测不执行SQL，不使用90条报告查询选模，不替换线上模型。

小测已完成：pair_gap_pilot 的seed17、30轮结果为两组等权准确率85.321%，低于匹配的原损失86.156%及XGBoost排序88.106%。训练输出与分数重放一致，未通过扩大实验门槛；不进行该变体的全量训练或SQL测试。

参数锚定小测已完成：seed17、30轮、保留错对强化与EMA，固定0.001惩罚使两组等权准确率为87.073%，低于匹配对照88.229%和XGBoost排序88.106%。独立920对重算一致；未扩大训练，未执行SQL。参数偏移减小但本轮没有准确率收益。见structure_coverage20/parameter_anchor_pilot/REPORT.md。

低温度小测完成，seed17、30轮、920对独立重算准确率87.978%，低于匹配原温度88.229%及XGBoost排序88.106%，不扩大。近期10项小测汇总见structure_coverage20/recent_model_tuning_audit/REPORT.md。

训练期统计特征重建小测完成：固定seed17、30轮，920对独立重算准确率86.276%，低于匹配对照88.229%和XGBoost排序88.106%，不扩大。重建误差相对均值预测器仅小幅改善；辅助头不进入推理。

冻结编码器的线性读出诊断完成：三个固定种子平均86.763%，原读出86.442%，仍低于XGBoost排序88.106%。seed17总分不变，双方各纠正8对而共同错误96对；简单更换读出不足以达到目标。仅离线诊断，未部署、未读取90查询作选模。

三个固定错对强化EMA模型的参数平均完成：86.906%准确率，低于XGBoost88.106%及同父模型分数平均88.693%，不扩大。训练梯度4批次诊断发现初始模型4/4、训练末模型1/4的跨类负点积，不作为因果或收益结论。

梯度投影小测已完成：seed17、30轮、两组等权准确率87.264%，匹配对照88.229%，XGBoost排序88.106%。1170步中591步投影；冲突、同向、单类、零梯度四项测试与920对独立重算通过。未扩大，未执行SQL或部署；本次未改善准确率，不能把先前冲突诊断视为已证明的泛化原因。目标仍未完成。
