# AutoDOP 消融与成本实验补充

状态：complete。所有实验保持冻结模型；只进行串行 SQL 测试。


本轮主要结论：12条诊断面板的固定异构配置比同一策略的统一DOP约束平均快36.19%（11/12获益）；这不是相对逐查询最佳候选统一DOP的收益。竞争边特征屏蔽的实测差异约0.85%，查询重采样区间跨零，证据不足以证明本面板上有稳定收益。串行负载修正0/48次触发，不能证明高负载性能改善。

全部288次执行已核验，含72次预热和216次正式计时；失败和缺失均为0。没有修改生产模型、没有并发压测。尚未补充重新训练后的网络结构消融，以及FE特征提取/安装的独立计时。

## 消融与敏感性

冻结模型关闭竞争边特征后，169/200 条查询改变 DOP，共改变 515 个 fragment 决策。仍保留竞争注意力通道，屏蔽的是边特征；这不是重训后的架构消融。

搜索实验使用原开发数据中按 fragment 数覆盖选出的 6 个计划，3 个随机种子，64 次 MCTS 迭代。完整搜索、取消等价分组、取消注意力排序采用同一成本模型。分数只代表模型预测的效用，不代表 SQL 实测延迟。

搜索完整配置平均 0.898 秒；统一 DOP 穷举平均 0.067 秒，其候选数更少，不能按相同预算比较。
- 对比 no_equivalence：完整搜索分数更高/相同/更低 = 14/0/4，该配置平均 0.882 秒。
- 对比 no_attention_order：完整搜索分数更高/相同/更低 = 13/0/5，该配置平均 0.860 秒。

## 使用已有计时的查询级约束对照

统一 DOP 根据冻结模型各非 gather fragment 的对数概率之和选定；gather 固定为 1，再从原五档实测记录取对应延迟。下面是回溯组合的诊断结果，并非新一轮同期实测，也不是逐查询最优统一 DOP。当前策略记录包含置信度回退。该较弱的策略统一约束基线不改变原全200相对最佳候选统一DOP平均退化约7.22%的结论。
- all200: 策略平均 2241.79 ms，策略选择的统一 DOP 平均 3745.71 ms，相对降低 40.15%。
- positive90: 策略平均 1637.86 ms，策略选择的统一 DOP 平均 4056.57 ms，相对降低 59.62%。
- other110: 策略平均 2735.92 ms，策略选择的统一 DOP 平均 3491.36 ms，相对降低 21.64%。

## 训练成本

在原训练划分的 130 个计划上，以原损失函数运行 1 轮预热、3 轮正式计时；平均 0.411 秒/轮，数据/图/优化器准备 2.182 秒，进程峰值 RSS 763.5 MiB。未保存或替换模型。这是训练微基准，不是原 1000 轮训练任务的实测总时长，也不包括数据采集和教师标签搜索。
